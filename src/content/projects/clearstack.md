## Context

ClearStack Dev is a marketing site for a software agency serving small businesses in Minnesota. The site needs to explain custom software services quickly for non-technical buyers while still giving enough detail to show technical credibility.

## Role

I built the site structure, page experience, and frontend implementation. The work focused on clear service messaging, responsive layouts, and a maintainable Astro codebase that can keep evolving with the business.

## Stack

The site uses Astro 5 for static pages, Vue 3 islands for interactive UI where needed, TypeScript for implementation confidence, and Tailwind CSS v4 for the visual system. It deploys to Cloudflare Pages.

## Constraints

The audience is small-business operators, so the interface needs to be approachable rather than overly technical. The implementation also needs to stay lightweight, fast to ship, and easy to maintain without a large application backend.

## Outcome

The live site gives ClearStack Dev a focused web presence with service context, calls to action, and a technical foundation that can support future content and conversion improvements. It remains featured because it is the strongest client-facing project in the portfolio.
