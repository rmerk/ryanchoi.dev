## Context

ryanchoi.dev is a ground-up redesign of my personal portfolio and blog. The project replaces an older single-page site with a content-driven static site that can support project entries, writing, resume content, and GitHub activity.

## Role

I designed and built the site end to end, including the Astro routing structure, shared layouts, content collections, theme system, resume presentation, project cards, and deployment workflow.

## Stack

The site uses Astro 5, TypeScript, Tailwind CSS v4, Astro Content Collections, and Astro View Transitions. Blog posts and projects are authored as Markdown content, while resume data is maintained in typed TypeScript arrays.

## Constraints

The site needs to feel polished without becoming heavy. It is deployed as static output to a VPS, so the architecture favors simple content files, minimal client-side JavaScript, and predictable build/deploy behavior.

## Outcome

The current site provides a multi-page portfolio foundation with writing, project, resume, and GitHub signal surfaces. It remains featured because it demonstrates the portfolio system itself and the frontend craft behind the site.
